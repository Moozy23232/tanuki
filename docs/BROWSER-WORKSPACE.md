# 浏览器工作区

Tanuki 使用独立 Android WebView profile，不与管理页共享 Cookie/站点存储；不是 Via 内核或 Windows 内核。实现入口为 `AgentBrowserController`、`AgentBrowserPage`、`BrowserService` 和 `BrowserOverlayWindow`；本轮与历史验证边界统一见 [TEST-REPORT](TEST-REPORT.md)。

## 授权

- 当前工具连接默认获准。触碰网页先暂停AI、使旧票据失效并拦截该次触摸，再询问是否收回。
- 「继续交给 AI」立即恢复原连接；「临时接管」期间连续 **30 秒未点击、滑动或输入**就默认交回 AI，交互重置倒计时。地址栏、原生工具栏、完整页和小窗/WebView 的触摸、键盘/输入均计入操作。
- 「撤销 AI 权限」是持久撤销，只有用户主动交回才恢复；不被 30 秒计时、切页、后台或重启覆盖。倒计时到期重新授权同一当前连接，旧操作票据不会恢复。
- 切换页面、Activity重建、后台和小窗不自行撤销。界面及通知显示状态并可收回/停止；RPC不能自行授权。
- 权限只针对应用发布的当前连接UUID，不等于已证明的模型/DSH会话身份。提交、发送、付款、删除等仍需业务确认；不保证撤回已经发出的网络请求。

## 使用入口

| 功能 | 入口与行为 |
|---|---|
| 浏览/搜索 | 标题右侧紧凑输入框，首次聚焦全选、再次点击定位光标；前往箭头/键盘Go打开，搜索按已选引擎 |
| 多页 | 标题下方的叠页图标与数量角标→总览，`+`新建、卡片切换/关闭；不设固定页数上限 |
| 收藏/历史/下载 | 顶部工具栏菜单→列表，收藏支持文件夹，列表支持筛选 |
| 工具箱 | 查找、缩放、完整网页截图、页面显示模式 |
| 页面模式 | 新页默认Windows PC UA；旧标签保留显式模式。移动/Windows/Mac/Linux切换须确认重载，不更换内核 |
| 全屏 | 顶部工具栏进入；隐藏浏览器/应用导航及系统栏，右上角按钮/返回键退出；复用WebView，不主动重载，操作进度保留 |
| 小窗 | DSH页「浏览器小窗」，用户允许系统悬浮窗后跨应用显示；顶部拖动、左右下角调大小，可收起/返回完整浏览器 |
| 权限/后台 | 工具栏下方、分类设置和前台通知提供收回/交回/停止入口 |
| 搜索引擎 | 分类设置→通用：必应、百度、Google、DuckDuckGo |

角标超过99显示 `99+`，总览和无障碍说明保留真实数量。创建、手势弹窗、记录恢复不再按12页截断；仍按需创建WebView，保留无手势弹窗拦截、协议限制及16 MiB元数据读取保护，实际容量受设备资源约束。

窄屏各页共用浮动导航，原生列表末尾预留可滚动的避让空间；底部被键盘占用时收起。网页延伸到导航后方透明透显，不抓取或重绘WebView；全屏隐藏导航，宽屏保留侧栏。

## 页面、后台与数据

恢复标签先还原地址/标题，选中才加载；只让当前页活跃，已访问页保留WebView但离开绘制树。后台容器不可见、不可触摸且屏蔽无障碍焦点，小窗/完整浏览器重新挂载同一WebView，不调用全局 `pauseTimers()`。

用户启动的前台服务维持浏览与下载；系统仍可回收或限制网络，不承诺无限后台。重启可恢复地址、收藏、历史、偏好，不承诺未提交表单。系统悬浮窗权限和AI工具授权是两件事；撤销前者只移除小窗。

Windows PC是UA/宽视口设置，不能保证所有站点桌面布局。页面历史/偏好存于私有目录，不是无痕模式。DSH 外链在独立标签打开，管理 origin/端口和带管理 token 的地址仍被阻止。DeepSeek 官方登录使用有时限的一次性票据和专用临时标签，支持先开空白窗口再异步导航；仅将当前管理连接声明的 `/callback` 交给原生转发，其他管理导航仍拒绝。登录标签不提供 AI 读写/截图、不存历史，完成后关闭；Cookie 不复制给管理页。真实登录尚未验收，详情见 [安全](SECURITY.md)。

## AI范围与下载

- 文字/控件只涵盖已加载主文档，每次最多20000字符/100控件，可按cursor继续；扫描上限50000节点并报告截断，不含未加载虚拟内容或跨origin iframe。
- 整页PNG使用完整文档绘制，不能退回小窗裁切；最大边2048px并有编码大小上限，大页面细节需要DOM/滚动辅助。改变全局绘制设置或进程边界必须重新验证尾部像素、AI缩放和收起小窗。
- 下载须原生确认，单文件上限256MiB、并发最多2个，真实字节进度与取消；未知总量不伪造百分比。下载/截图在列表中打开、经SAF导出或删除，内部以UUID寻址。
- 不自动授予上传、相机、麦克风或定位。付款/发布等另行确认。

资源回调不能证明覆盖每一跳重定向，不宣传完整网络/SSRF沙箱。真实模型、真实账号登录、HyperOS长期后台和其他系统版本仍待验收，详见 [安全](SECURITY.md) 与 [测试](TEST-REPORT.md)。
